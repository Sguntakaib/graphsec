### 4. DESIGN-ALIGNED STRIDE MAPPING LOGIC:

#### 🎯 WEBAPP THREATS:
**SPOOFING (Authentication-based)**:
```
Trigger Logic: authentication_method + application_type + data_sensitivity
- Static website/blog + Public data only = NO spoofing threat
- Interactive web app + No Authentication = HIGH spoofing threat  
- SaaS/E-commerce + Basic auth + Financial data = CRITICAL spoofing threat
```

**TAMPERING (Input Processing)**:
```
Trigger Logic: input_validation + application_type + database_connection
- Static website + Read-only = NO tampering threat
- Interactive app + No validation + Database = HIGH tampering threat
- E-commerce + Basic validation + Database = MEDIUM tampering threat
```

**REPUDIATION (Audit Requirements)**:
```
Trigger Logic: logging_monitoring + data_sensitivity + authorization_model
- Public info only + No authorization = NO repudiation threat
- Financial/Health data + No logging = HIGH repudiation threat
- User accounts + Basic logging = MEDIUM repudiation threat
```

**INFORMATION_DISCLOSURE (Data Protection)**:
```
Trigger Logic: https_enforcement + data_encryption + data_sensitivity
- Public info + HTTP only = LOW disclosure threat
- Financial data + HTTP only = CRITICAL disclosure threat
- Personal data + HTTPS preferred = MEDIUM disclosure threat
```

**DENIAL_OF_SERVICE (Availability Protection)**:
```
Trigger Logic: exposure_level + rate_limiting + application_type
- Internal network only = NO DoS threat
- Public internet + No rate limiting = HIGH DoS threat  
- Behind CDN/WAF + No rate limiting = LOW DoS threat
```

**ELEVATION_OF_PRIVILEGE (Access Control)**:
```
Trigger Logic: session_management + authorization_model + application_type
- No authorization needed = NO privilege escalation threat
- Fine-grained RBAC + Basic sessions = HIGH privilege escalation threat
- Admin dashboard + No authorization = CRITICAL privilege escalation threat
```

#### Phase 2: Enhanced Context-Aware Mapping Logic
```python
class UniversalContextualThreatAnalyzer:
    """Context-aware threat analysis for all node types"""
    
    def analyze_threats_by_node_type(self, node_type: str, responses: Dict[str, Any]) -> List[Threat]:
        if node_type == "WebApp":
            return self._analyze_webapp_threats(responses)
        elif node_type == "API":
            return self._analyze_api_threats(responses)  
        elif node_type == "Database":
            return self._analyze_database_threats(responses)
        else:
            return []  # Fallback to existing mapping
    
    def _analyze_webapp_threats(self, responses: Dict[str, Any]) -> List[Threat]:
        threats = []
        context = self._get_webapp_context(responses)
        
        # Only generate threats where contextually relevant
        if context.needs_authentication:
            threats.extend(self._webapp_spoofing_threats(responses, context))
        if context.processes_input:
            threats.extend(self._webapp_tampering_threats(responses, context))
        if context.handles_sensitive_data:
            threats.extend(self._webapp_disclosure_threats(responses, context))
        if context.publicly_exposed:
            threats.extend(self._webapp_dos_threats(responses, context))
        if context.has_authorization:
            threats.extend(self._webapp_privilege_threats(responses, context))
        if context.requires_audit:
            threats.extend(self._webapp_repudiation_threats(responses, context))
        
        return threats
    
    def _get_webapp_context(self, responses: Dict[str, Any]) -> WebAppContext:
        app_type = responses.get("webapp_application_type", "")
        data_sensitivity = responses.get("webapp_data_sensitivity", [])
        exposure = responses.get("webapp_exposure_level", "")
        auth_model = responses.get("webapp_authorization_model", "")
        
        return WebAppContext(
            needs_authentication=self._needs_auth(app_type, data_sensitivity),
            processes_input=self._processes_input(app_type),
            handles_sensitive_data=self._handles_sensitive(data_sensitivity),
            publicly_exposed=self._is_public(exposure),
            has_authorization=self._has_auth_model(auth_model),
            requires_audit=self._needs_audit(data_sensitivity, auth_model)
        )
```

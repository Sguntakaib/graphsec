Detailed Technical Roadmap (end-to-end blueprint)
A. Product & UX Architecture
A.1 User roles & tenancy

Tenants: Org → Workspaces → Projects → Diagrams.

Roles: OrgOwner, Admin, Modeler, Viewer, Auditor.

Permissions: Row-level + graph-level (node/edge access lists, “confidential” nodes).

A.2 Core objects & taxonomy (domain-constrained)

Node categories:

Actors: Attacker, Insider, Third-party, Service Account.

Targets/Assets: WebApp, API, Database, S3/Blob, VM/Container, Mobile, SaaS app (O365, GDrive).

Surfaces/Vulns: SSRF, SQLi, IDOR, CSRF, RCE, XXE, Deserialization, Misconfig (S3 public), Weak IAM Policy.

Vectors: Phishing, Supply chain, Credential stuffing, OAuth misuse.

Controls: WAF, EDR, CSP, IAM policy, Network ACL, DLP, Egress proxy, Secret manager, Token binding, mTLS.

Zones: Internet, DMZ, Corp, Prod, PCI, Cloud VPC/Subnet.

Signals: Alert, Detection rule, Telemetry stream.

Edge types: connects_to, trust_boundary, data_flow, exfil_path, authenticates_as, exploits, mitigates, observes.

Attributes: CIA impact scores, likelihood, exposure, tags (MITRE IDs, CVE/CWE), data classification (PII/PHI/PCI).

A.3 Canvas UX (React)

Left rail: Security element library with search + favorites.

Center: Node-based canvas (pan/zoom, snap-to-grid, auto-layout).

Right panel: Properties (node/edge), MITRE/CVE lookups, controls recommendations, simulation outcomes.

Bottom: Simulation timeline (steps, probabilities, triggered alerts).

Collab: Cursors, comments, change history, presence, @mentions.

Accessibility: WCAG 2.2 AA, keyboard-only editing, high-contrast palette.

B.2 Containers & data flow

Frontend (Next.js + React): SPA/SSR hybrid, connects to GraphQL/REST and WebSocket gateways.

API Gateway: Envoy/Nginx Ingress with WAF, request authz, rate limits, JWT verification.

Model Service: CRUD for projects/diagrams; versioning, diff, export/import (JSON, STIX/TAXII).

Simulation Service: Executes threat rules and attack-path computations on the graph; returns stepwise outcomes & probabilities.

Inference Service: Suggests likely paths/mitigations; maps to MITRE, recommends controls.

Integrations Service: Pulls CVE/NVD feeds, MITRE ATT&CK, vendor connectors (read-only to start).

Collab/CRDT Gateway: Real-time document state sync (yjs/automerge), presence, comments, replay.

Event Bus: NATS/Kafka for: diagram.updated, simulation.ran, intel.updated, audit.logged.

Data stores:

PostgreSQL: tenancy, users, RBAC, billing, audits.

Neo4j: nodes/edges, versions, computed paths.

Redis: sessions, CRDT snapshots, short-lived sim caches.

Object storage: exports, assets (icons, logos).

D. Simulation & Inference Design
D.1 Threat Rule DSL (declarative)
id: rule.surf.ssrf.basic
when:
  - node.type == "Surface"
  - node.subtype == "SSRF"
  - exists(edge from Actor to node)
evaluate:
  steps:
    - name: "Trigger SSRF request"
      effect:
        - follow: edges(DATA_FLOW where direction == "egress" and zone == "internal")
        - set(prob += 0.2 if Control[egress_proxy].coverage < 0.5)
    - name: "Pivot to internal metadata"
      condition: target.asset.subtype == "IMDS" 
      effect:
        - set(confidentiality_impact = "High")
        - recommend(Control: "IMDSv2 + metadata firewall")
outputs:
  mitre: ["T1190", "T1552.001"]
  signals: ["WAF.alert", "Proxy.logs"]

D.2 Attack-path computation

Core algorithm: constrained path search (multi-criteria Dijkstra/A* on the graph) with:

Edge weights from likelihood, exposure, control coverage.

Cutsets for trust boundaries.

Dominance pruning to avoid combinatorial explosion.

Outputs:

Sequence of steps with probability bands (Low/Med/High).

Affected assets and data classes.

Control coverage gaps + ranked mitigations.

D.3 Inference service

Combines: rules outputs + MITRE mappings + org’s current controls.

Suggests:

Missing detections (e.g., “Add egress DNS logging on prod VPC”).

Top-3 “bang-for-buck” mitigations (coverage vs. cost).

Alternative paths a skilled attacker might take (what-if).

G.4 Security Engineering

AuthN: OIDC (Auth0/Okta/Azure AD/GSuite), PKCE; SCIM for user provisioning.

AuthZ: Policy engine (OPA/Topaz) for ABAC over RBAC (attrs: tenant, workspace, role, clearance).

Secrets: Cloud KMS + Secret Manager, short-lived tokens.

Data: Per-tenant envelope encryption; RLS in Postgres; attribute-based filtering in Neo4j queries.

AppSec: CSP, Trusted Types (to protect canvas UI), strict DOMPurify for notes, SSRF guards on any URL fetchers, file-type validation for uploads.

Supply chain: Dependency pinning, Renovate, provenance (SLSA L3).

Compliance: SOC2 Type II roadmap; audit trails immutable (WORM storage for 1y+).

K. Performance & Cost Guardrails

Graph scale: Target 50k nodes / 200k edges per workspace; shard by project; read replicas.

Compute: Sim Svc with job queue (Argo/KEDA) scaling to N workers; max graph slice/window per run to bound cost.

Caching: Memoize common subpaths; LRU on Redis; nightly precompute for popular models.

FinOps: Tagging, budget alerts, per-tenant cost meters; archive cold diagrams to cheaper storage.

B. Terraform/IaC highlights

VPC with private subnets, NAT, egress proxy where applicable.

SGs least-privilege; restrict DBs to services; no public DB.

OIDC workload identity for pods; no long-lived static creds.

C. Risk register (top 5)

Overconfident simulations → communicate uncertainty bands; allow user-tuned priors.

Graph bloat → archive versions; subgraph focus windows.

Vendor logos/IP → licensing policy + user-uploaded assets only at MVP.

Real-time scale → shard by workspace, backpressure, WS autoscaling.

Multi-tenant isolation → RLS + OPA policies, tenancy fuzz tests.

# Double-Click Questionnaire Implementation Plan

## Overview
This document explains how the double-click questionnaire functionality is implemented for all intelligent node types including API, Database backup (Backup), and Database monitoring (Monitoring) nodes.

## How Double-Click Questionnaire Works

### 1. Frontend Components

#### CustomNode.js (Double-Tap Detection)
- Detects double-tap/double-click events on nodes using a tap counter with 300ms window
- When double-tap is detected, dispatches a custom `nodeDoubleTap` event to the window
- Works for all node types without any restrictions

```javascript
const handleNodeClick = (event) => {
  setTapCount(prev => {
    const newCount = prev + 1;
    
    if (tapTimer.current) {
      clearTimeout(tapTimer.current);
    }
    
    tapTimer.current = setTimeout(() => {
      if (newCount === 2) {
        // Double tap detected
        const customEvent = new CustomEvent('nodeDoubleTap', {
          detail: { nodeId: id, nodeData: data }
        });
        window.dispatchEvent(customEvent);
      }
      setTapCount(0);
    }, 300); // 300ms window for double tap
    
    return newCount;
  });
};
```

  1. `node.data.questionnaireResponses` (for auto-created dependent nodes)
  2. `node.questionnaireResponses` (for regular nodes)

```javascript
// Enhanced double-click handler with improved state restoration
const handleNodeDoubleTap = async (event) => {

  const node = nodes.find(n => n.id === nodeId);

  }
  
  // Open questionnaire with existing answers
  setCurrentQuestionnaireAnswers(existingAnswers);
  setShowSecurityQuestionnaire(true);
};
```

### 3. State Management

#### Questionnaire Response Storage
Completed questionnaires store responses in multiple locations:
1. **Node Data**: `node.data.questionnaireResponses` (primary for auto-created nodes)
2. **Node Root**: `node.questionnaireResponses` (for regular nodes)
3. **Backend Database**: Via diagram persistence APIs

#### State Restoration Process
When double-clicking a completed questionnaire:
1. **Detect Double-Click**: CustomNode dispatches `nodeDoubleTap` event
2. **Find Existing State**: App.js checks node data, then backend API
3. **Restore Questionnaire**: SecurityQuestionnaire opens with pre-filled answers
4. **Enable Editing**: User can review/modify existing responses
